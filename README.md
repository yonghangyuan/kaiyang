# 开阳 (Kaiyang)

北斗七星第六星——主司"开明启智，照亮黑暗"。
全球开源情报地理标注与态势感知系统。

## 架构

```
开阳 (应用层)
  ├── 数据源接入 (RSS/API/MCP → 全球事件)
  ├── 地理标注 (地名→坐标→地图标记)
  ├── 重要性分析 (信源可信度 + 事件影响力)
  └── 态势感知 (时间线 + 热力图 + 关联图)

天枢 (治理层)
  ├── 三层闸门 (搜索→分析→决策, 每步可审计)
  ├── 贝叶斯融合 (多源矛盾信息不二选一)
  └── 决策引擎 (预防原则·安全第一·期望效用)
```

## 技术栈

- 后端: Python/FastAPI (复用天枢 server)
- 地图: Leaflet + CartoDB/ESRI 瓦片
- 数据源: RSS/API/MCP 协议
- AI: DeepSeek v4-pro / GLM-5V / SenseNova-SI

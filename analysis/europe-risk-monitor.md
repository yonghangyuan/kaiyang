# 欧洲风险监测协议（2026-08-13 建立）

> **来源**：知乎帖《天启骑士降临》→ 按三层框架降级为监测协议：预言降级为指标，天启降级为阈值。
> **性质**：活文档。指标基线随每期数据更新。
> **数据管道**：开阳信源（Politico EU / Euractiv / Euronews / DW / France24 / 百度·欧洲风险 / GDELT）

## 背景帖的三层判定（存档）

- **可证实层**：欧洲 GDP 占比 25%→15%（2000→2026）；德国去工业化（博世 2 万裁员、汽车业再裁 3 万计划、约 20 万制造业岗位已失）；法国 2025 一年三任总理；AfD 民调 28%（绿党+社民党之和的 1.05 倍）；2026-02-28 美以击毙哈梅内伊、霍尔木兹受威胁——"欧洲将发生极端事情"被主流分析背书。
- **不透明层**："上层疯狂/虚假宣传"——不可证伪；部分映射（布鲁塞尔技术官僚 vs 选民反弹：默茨对冯德莱恩 27 条最后通牒）。
- **断言层**：天启意象、种族仇杀级预测——信仰层，不进入监测指标，只保留尾部风险观察。

## 触发规则

- **任意 2 项红灯** → 预案启动：撤离评估、资产归集、路线确认（对在欧华人）。
- **任意 3 项黄灯** → 准备期：证件与资产分散、通讯备份、应急联络人。
- **全部绿灯** → 常态监测，不因任何单一"天启式"文章改变生活安排。

## 华人避险清单（非天启版）

1. **证件**：护照有效期 ≥2 年、永居/签证备份扫描件（云端+实体两处）、出生证明/公证双份。
2. **资产**：跨境账户至少一个（如香港/新加坡）、现金+黄金小比例配置、房产流动性评估。
3. **路线**：确定一个可投靠的境外节点（亲友或城市），预算一张任何时候可走的票。
4. **通讯**：家人联络暗号约定（遇事一句话确认安全）、使领馆紧急联系方式存离线。
